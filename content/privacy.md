# Privacy policy

botstopper.net is a marketing and documentation site. This page describes
what the website itself does with your data. The BotStopper product, when
you run it on your own infrastructure, processes requests for the sites it
protects; that processing happens on your servers, under your control.

What this site does:

- Serves static pages and documentation. This website does not use
  tracking cookies or third-party analytics scripts.
- Standard web server logs may record request data (URL, timestamp, user
  agent) for operational purposes such as debugging outages and abuse.

What this site does not do:

- It does not sell or share personal data with third parties.
- It does not run advertising.

The documentation is open. Fetch it as HTML or as Markdown with any tool
you like; see [llms.txt](https://botstopper.net/llms.txt) for the
machine-readable index.

[me@xeiaso.net](mailto:me@xeiaso.net).
