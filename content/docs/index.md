# BotStopper documentation

[The upstream Anubis documentation](https://anubis.techaro.lol/docs) covers the shared features.
These guides describe the additions and changes in BotStopper.

- [Installation](installation.md): binary packages, Docker, Podman, and Kubernetes.
- [Configuration](configuration.md): Docker Compose options and the local example.
- [Customization](customization.md): overlay folders, CSS, fonts, images, and message titles.
- [Headless browser detection](headless-browser-detection.md): detector configuration, client hints, Fetch Metadata, policies, metrics, and limits.
- [Custom challenge methods](challenge-methods.md): Soteria configuration and browser requirements.
- [Proxy and service upgrades](upgrades.md): TLS connection pools and systemd instance paths.
