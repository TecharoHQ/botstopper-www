# BotStopper documentation

[The upstream Anubis documentation](https://anubis.techaro.lol/docs) covers the shared features.
These guides describe the additions and changes in BotStopper.

- [Installation](/docs/installation): binary packages, Docker, Podman, and Kubernetes.
- [Configuration](/docs/configuration): Docker Compose options and the local example.
- [Customization](/docs/customization): overlay folders, CSS, fonts, images, and message titles.
- [Headless browser detection](/docs/headless-browser-detection): detector configuration, client hints, Fetch Metadata, policies, metrics, and limits.
- [Custom challenge methods](/docs/challenge-methods): Soteria configuration and browser requirements.
- [Proxy and service upgrades](/docs/upgrades): TLS connection pools and systemd instance paths.
